## Project 5

**Web Project: Homeland**

This website was developed based on a Figma design and implemented using HTML, CSS, and responsive web design techniques. The goal of the project is to accurately recreate the original visual interface while providing a smooth user experience across different devices and screen sizes.

## Project Description

This project represents a complete conversion from a Figma design into a functional website, applying web development and layout best practices.

### Main Features

- Fully responsive design.
- Custom fonts based on the Figma design.
- Modular code organization.
- Clean structure for easier maintenance and scalability.

## Technologies and Techniques Used

- **HTML** for the website structure.
- **CSS** for styling, including:
  - Normalize.css to ensure consistency across browsers.
  - `@font-face` for locally hosted custom fonts.
  - Flexbox and/or CSS Grid for responsive layouts.
- **Visual Studio Code** as the development environment.
- **Live Server** for real-time preview during development.
- **Git and GitHub** for version control.
