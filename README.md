# web-project-homeland

## Project 6

**Web Project: Homeland**

This project is a responsive travel destinations website designed to inspire users to explore different places around the world. It uses CSS Grid Layout to organize content in a clear and responsive structure, along with shadow effects (`box-shadow` and `text-shadow`) to add depth, enhance the visual design, and improve readability.

## Main Features

- **Responsive design:** The layout adapts to different screen sizes using CSS Grid.
- **CSS Grid Layout:** Provides a clean and organized structure for the website content.
- **Shadow effects:** `box-shadow` and `text-shadow` are used to add depth and highlight visual elements.
- **Destination gallery:** Features images and information about different locations.
- **Intuitive navigation:** A clear structure makes it easy for users to explore the website.
- **Content-focused design:** Combines destination descriptions and high-quality images to create an engaging visual experience.

## Technologies Used

- **HTML5** — Semantic structure and organization of the website.
- **CSS3** — Styling, responsive design, CSS Grid, and visual effects.
- **CSS Grid Layout** — Used to create flexible and responsive content layouts.
- **Git & GitHub** — Version control and project hosting.
- **GitHub Pages** — Deployment of the live website.
